# HumanizeAI Engine

## Professional Content Restructuring & Text Optimization Dashboard

HumanizeAI Engine is a Streamlit-based web application designed to restructure and optimize AI-generated text using a lightweight local text transformation engine.

The application provides a clean dashboard for processing text, selecting optimization modes, viewing output metrics, and maintaining local usage statistics.

## Features

* AI-generated text input workspace
* Local text restructuring engine
* Standard Humanizer mode
* Ultra Bypass Mode
* Balanced Professional tone option
* Creative Academic tone option
* Original and processed word-count comparison
* Human-authenticity diagnostic indicator
* Local SQLite usage database
* Usage statistics dashboard
* Total processing count
* Total words processed
* CSV export of usage logs
* Responsive Streamlit interface
* Dark premium-style UI
* No external API key required for the included processing engine

## Installation

### 1. Clone or download the project

Download the project ZIP and extract it to your computer.

### 2. Open the project folder

Open a terminal or command prompt inside the project directory.

### 3. Install dependencies

Run:

```bash
pip install -r requirements.txt
```

### 4. Start the application

Run:

```bash
streamlit run app.py
```

The application will normally open at:

```text
http://localhost:8501
```

## How to Use

### Step 1 — Enter Text

Paste your AI-generated or draft content into the input workspace.

The application recommends using at least 20 words, although the current validation accepts text containing 5 or more words.

### Step 2 — Select Optimization Tier

Choose one of the available processing modes:

* Standard Humanizer
* Ultra Bypass Mode

### Step 3 — Select Target Tone

Choose:

* Balanced Professional
* Creative Academic

### Step 4 — Execute Processing

Click:

**Execute Humanization Engine**

The application processes the text locally and displays the transformed output.

### Step 5 — Review Results

The output workspace displays:

* Processed text
* Original word count
* Output word count
* Human-authenticity diagnostic indicator

## Usage Analytics

HumanizeAI Engine maintains a local SQLite database named:

```text
saas_metrics.db
```

The database records:

* Processing timestamp
* Selected processing mode
* Original word count
* Processed word count

The sidebar provides a simple analytics dashboard showing total runs and total processed words.

## CSV Export

When usage records are available, the application provides a CSV download option.

The exported file contains the stored usage information and can be used for basic reporting or analytics.

## Privacy

The included processing engine operates locally within the application.

No external AI API is required by the current implementation.

The application does not require an API key for its built-in text transformation functionality.

## Deployment

The application can be deployed on Streamlit-compatible hosting platforms.

For Streamlit deployment, the main entry point is:

```text
app.py
```

Make sure `requirements.txt` is included in the repository.

## Important Notes

This project uses a lightweight rule-based text transformation engine. It does not contain a proprietary machine-learning model or external AI detector integration.

The displayed human-authenticity percentage is an application diagnostic indicator generated by the interface and should not be interpreted as a verified score from GPTZero, Turnitin, Copyleaks, or another third-party detection service.

Users should review transformed content before publishing or submitting it.
